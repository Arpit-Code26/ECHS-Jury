# CIC-IDS2017 DATASET PREPARATION GUIDE
## CYBERSENTINEL: Network Intrusion Detection System

### 1. Overview
CyberSentinel is designed and benchmarked against the official **Canadian Institute for Cybersecurity (CIC-IDS2017)** dataset from the University of New Brunswick (UNB).

Official dataset source and documentation:
- **Project Portal:** https://www.unb.ca/cic/datasets/ids-2017.html
- **Direct Download Page:** https://www.unb.ca/cic/datasets/ids-2017.html

The dataset includes benign traffic and authentic network attacks captured over 5 days (Monday to Friday) in July 2017.

---

### 2. Recommended CSV Files for CyberSentinel
The original dataset comprises 8 CSV files generated by CICFlowMeter. CyberSentinel supports all 8 files, but focuses on these core threat categories:

| Day & Time | File Name | Attack Categories Present |
| :--- | :--- | :--- |
| **Friday Afternoon** | `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv` | **DDoS**, BENIGN |
| **Friday Afternoon** | `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv` | **PortScan**, BENIGN |
| **Wednesday** | `Wednesday-workingHours.pcap_ISCX.csv` | **DoS Hulk**, **DoS GoldenEye**, **DoS slowloris**, BENIGN |
| **Tuesday** | `Tuesday-WorkingHours.pcap_ISCX.csv` | **FTP-Patator**, **SSH-Patator**, BENIGN |
| **Thursday Morning** | `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv` | **Web Attacks** (Brute Force, XSS, SQLi), BENIGN |

---

### 3. Step-by-Step Placement Guide

1. **Download the CSVs:**
   Download the selected CSV files or the `GeneratedLabelledFlows.zip` archive from the UNB portal.
2. **Place in Raw Directory:**
   Copy the CSV files into the CyberSentinel raw dataset folder:
   ```
   CyberSentinel/dataset/raw/
   ```
3. **Inspect via Dashboard or CLI:**
   Open the CyberSentinel dashboard and navigate to **"2. Dataset Analysis"** or run:
   ```bash
   python scripts/train_all.py --data-path dataset/raw/Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv
   ```
4. **Offline Demonstration Files:**
   CyberSentinel provides pre-generated lightweight test slices in `dataset/raw/`:
   - `demo_benign_traffic.csv`: Pure benign background traffic for testing false-positive rates.
   - `demo_attack_traffic.csv`: Combined multi-attack traffic (DDoS, DoS Hulk, PortScan, FTP-Patator, SSH-Patator) for demonstrating live detection.

---

### 4. Data Leakage Precautions
When preparing or filtering the dataset, ensure:
- Never include the `Label` column as an input feature during model training.
- Flow identifiers (`Flow ID`, `Source IP`, `Destination IP`, `Timestamp`, `Source Port`) must be excluded from feature vectors. CyberSentinel's preprocessor automatically eliminates these fields to prevent overfitting to specific IP addresses.
