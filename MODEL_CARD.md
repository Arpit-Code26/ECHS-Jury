# CYBERSENTINEL: MODEL CARD

## 1. Model Details
- **System Name:** CyberSentinel Multi-Tier Intrusion Detection System
- **Model Version:** 1.0.0
- **Model Architectures:**
  1. **Random Forest Classifier (Baseline):** 100 estimators, max depth 16, balanced class weights, Scikit-learn.
  2. **XGBoost Classifier (Primary Advanced Tabular):** Histogram-based gradient boosted trees, multiclass softprob objective, max depth 6, subsample 0.8.
  3. **Deep Learning Autoencoder (Unsupervised Anomaly Detection):** Symmetric PyTorch MLP (Input 67 -> 48 -> 24 -> 16 Latent -> 24 -> 48 -> Output 67).
- **Serialization Formats:**
  - Scikit-learn & Preprocessors: `joblib` bundles with schema manifests.
  - XGBoost: Native JSON (`xgboost_model.json`) and `joblib`.
  - Autoencoder: PyTorch tensor `state_dict` (`.pt`) + Python model architecture class.

---

## 2. Intended Use
- **Primary Domain:** Defensive network flow traffic classification and anomaly detection.
- **Intended Users:** Security Operations Center (SOC) analysts, network administrators, computer science engineering researchers.
- **Out-of-Scope Use:**
  - Active intrusion prevention (IPS) or automated traffic blocking without administrative oversight.
  - Deployment on raw unencrypted payload data without flow-metric extraction.
  - Offensive reconnaissance or adversarial traffic generation.

---

## 3. Training & Benchmark Dataset
- **Base Dataset:** Canadian Institute for Cybersecurity (CIC-IDS2017) official dataset.
- **Target Threat Classes:**
  - `BENIGN`: Normal web and network operations.
  - `DDoS`: High-frequency volumetric denial-of-service floods.
  - `DoS Hulk`: Application-layer HTTP GET floods.
  - `PortScan`: Reconnaissance and port enumeration probing.
  - `FTP-Patator`: Brute-force credential attempts on port 21.
  - `SSH-Patator`: Brute-force credential attempts on port 22.
- **Input Dimension:** 67 canonical network flow features (durations, packet counts, inter-arrival times, flag ratios, header sizes).

---

## 4. Data Leakage Prevention Protocol
- **Strict Target Column Exclusion:** The ground truth `Label` is stripped prior to feature matrix generation.
- **Identity Attribute Elimination:** Flow IDs, Source IP, Destination IP, Source Port, and Timestamps are removed from the feature set to ensure models learn traffic patterns rather than memorizing specific network topologies or IP addresses.
- **Hold-out Stratification:** Imputers and scalers are fitted exclusively on training data and frozen before test inference.

## 6. Analytical Limitations & Bias
1. **Offline Flow Dependency:** Models require completed flow summaries (e.g., generated by CICFlowMeter). Incomplete or mid-stream active flows may require synthetic padding.
2. **False Positives in Novel Applications:** Autoencoders flag statistical anomalies. Non-malicious high-throughput data transfers (e.g., local database backups or large file uploads) may register high reconstruction error.
3. **Concept Drift:** As network protocols and attack techniques evolve, models must be periodically retrained on updated flow captures.
